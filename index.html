规则说明 · 炸金花（诈金花）

先说清楚

这是炸金花（诈金花），也叫「三张牌」。不是德州扑克：没有公共牌，没有翻牌 / 转牌 / 河牌，没有大小盲注，也不比花色。每人只发 3 张牌，比大小定胜负。

牌组

52 张，无大小王。点数大小：2 < 3 < 4 < … < 10 < J < Q < K < A。花色 ♠ ♥ ♣ ♦ 不分大小。

牌型大小（从大到小）

  1. 豹子（三条）：三张点数相同。比较点数，AAA 最大，222 最小。
  2. 同花顺：同花色且三张连续。AKQ 最大，234 最小。同花顺大于普通顺子。
  3. 金花（同花）：三张同花色但不连续。依次比最大、第二、第三张点数，花色不参与比较。
  4. 顺子：三张连续但不同花。AKQ 最大，234 最小。A23 不算顺子（A 只当大，不当 1），按单张处理。
  5. 对子：先比对子点数，再比剩下那张单牌。
  6. 单张：依次比最大、第二、第三张点数。

特殊规则：235 管豹子

不同花的 2、3、5（例如 2♠ 3♥ 5♣）可以击败任意豹子，包括最大的 AAA。

但 2、3、5 同花时不触发这条规则——因为 2、3、5 不连续，不构成顺子，所以同花 235 只是一手普通的金花，按金花规则比大小，打不过豹子。

如果双方都是特殊 235（都是不同花的 235），点数完全一样，按普通单张比较的结果是平局。

另外注意：特殊 235 只在面对豹子时管用，对其他牌型它就是一手「单张」，而且是最小的单张（5 高），会被对子、顺子、金花、同花顺打败。

下注规则

  • 开局每人先下底注（默认 10）进底池。
  • 闷牌（还没看牌）时每次跟注付 1 倍注额；看牌之后每次跟注付 2 倍注额。闷牌期间不能弃牌——想跑就先看牌，看完再决定。
  • 加注：把注额提到下一档（10 → 20 → 30 → 50 → 80 → 120 → 200 → 300），加注方按新注额付钱（闷牌 1 倍 / 看牌 2 倍）。
  • 比牌：付「跟注额的 2 倍」作为比牌费用，指定一名对手亮牌比大小，输的人直接出局。比牌平局时，发起比牌的一方判负。
  • 弃牌：看过牌之后才能弃牌，放弃本局，已经投进去的筹码不退。
  • 当只剩一名玩家没弃牌时，该玩家赢下全部底池。
  • 本游戏最多下注 6 轮，超过则所有未弃牌玩家强制摊牌，牌大的赢；摊牌平局则底池平分。
  • 筹码不足时可以全下：投入多少算多少。摊牌时按各人投入切分主池 / 边池——全下玩家最多只能赢自己投入对应的那一层，超出部分归还在局里、投入更多的玩家。

操作提示

  • 你的手牌在点击 【看牌】 之前是扣着的——不看牌就是闷牌，付钱少，但你自己也不知道自己是什么牌。
  • 电脑对手只根据自己的手牌和公开信息（底池、注额、谁看了牌、谁弃了牌）做决策，看不到你的底牌，也不会作弊。
  • 筹码输光后点【重置筹码】重新开始。

对手是谁

四位固定的电脑对手：皮尔·卡松、初六、阿星、发哥。 每局开始，他们各自随机分到一个性格——名字前面的小圆点就是性格颜色，点一下他的座位就能看到这家是什么性格、爱怎么打。

所有对手都看不到你的底牌；他自己闷牌时也不知道自己是什么牌，只能凭场面瞎猜。

性格池（8 种）

  • 愣头青　不管牌好坏都敢跟，一言不合就加注，最喜欢跟你硬闷
  • 老练　有大牌才跟，牌不行拔腿就跑
  • 偷鸡王　单张也敢跟你赌到底，最喜欢偷鸡唬人
  • 跟注站　不加注也不弃牌，就跟着你看到最后
  • 梭哈哥　一言不合就抬注，敢拿中等牌跟你全下
  • 老狐狸　最爱抓偷鸡，你越凶他越敢跟你比
  • 闷葫芦　死活不看牌，一路闷到摊牌
  • 急性子　不跟你磨，抓到机会就要求比牌

换对手人数或点【重置筹码】会重新随机分配性格。不管什么性格，豹子和同花顺都不会弃牌， 快摊牌时对子以上也不会白白扔掉。
